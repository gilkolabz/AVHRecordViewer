project

avh_record_viewer

Record Handler Tool: view/add/edit local patient records, find via numpad, folder views (table, pagination, pile), document scanning, local ML model document parsing, and more

Active notes

Functional but could look a lot better. Can send to homescreen as an app. Could use improved styling and presentation. Pending: real document types, better page-turn controls, a way to browse previous edits, desktop mode properly sized interface, importing records from other record hosts.

Launches

The following include hyperlinks to launch different instances of the project. baseline is the latest of the most “standard” implementation. Each instance is composed of individual components that do currently have variations or alternate combinations. A select few of these are also hyperlinked. A project release can compose the best elements of each concern, and these launchers surface some of that scope that cannot be seen in one baseline flow.
